## 2026-10-24 — PDF SAF export validation before destination mutation (source only)

- **Risk identified:** the native export handler fell back from `openOutputStream(uri, "wt")` to `openOutputStream(uri)`, equivalent to the provider-dependent non-truncating `"w"` mode.
