## Recovery preflight before SAF truncation — 2026-10-23

- **Production source changed: YES** (PR #7 branch only). A restore currently opens `ContentResolver.openOutputStream(target, "wt")` (or `"rwt"`) **before** `AquaWordHistory.restore()` checks its checksum. Opening that stream can truncate a pre-existing provider document immediately; a corrupt/missing recovery snapshot would then fail, but could already have destroyed the destination.
